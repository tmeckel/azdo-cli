## Command `azdo pipelines folder`

Manage Azure DevOps build definition folders. Folders are project-scoped
and organize pipeline definitions.


### Available commands

* [azdo pipelines folder create](./azdo_pipelines_folder_create.md)
* [azdo pipelines folder delete](./azdo_pipelines_folder_delete.md)
* [azdo pipelines folder list](./azdo_pipelines_folder_list.md)
* [azdo pipelines folder update](./azdo_pipelines_folder_update.md)

### ALIASES

- `folders`
